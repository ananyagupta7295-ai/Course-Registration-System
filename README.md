# Course Registration System

## About the Project
The Course Registration System is a desktop-based Java application developed to manage student course registrations.

## Technologies Used
- Java
- AWT (Abstract Window Toolkit)
- JDBC (Java Database Connectivity)
- MySQL
- MySQL Workbench
- IntelliJ IDEA

## Features
- Student registration
- Update student details
- Delete student records
- View registration history
- MySQL database connectivity
- User-friendly graphical interface

## Database
Database Name: `course_registration`

Table Name: `students`

## How to Run
1. Install Java JDK.
2. Install MySQL Server and MySQL Workbench.
3. Add MySQL Connector/J to the project.
4. Create the database using the provided `database.sql` file.
5. Configure your MySQL connection credentials.
6. Run `NewNewNewCourseRegistration.java` from IntelliJ IDEA.
